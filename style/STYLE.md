# NOIRXU IG 視覺規格 v1：日式商務高級風

定稿日期：2026-10-15。除非使用者明確要求，所有 IG 圖一律遵守本規格。

## 1. 規格
- 尺寸：1080 × 1350（4:5）。內部以 2 倍超取樣繪製，輸出縮回。
- 邊界：左 118、右 90；頂部 NOIRXU + 頁碼 + 細線（y=100）；左側直書標籤（x=48）。

## 2. 色彩（只准用這些）
| 名稱 | 色碼 | 用途 |
|---|---|---|
| 和紙白 PAPER | #F6F4EF | 主要底色 |
| 墨 INK | #1B1B1A | 主要文字、線 |
| 灰 GRAY | #74726C | 說明、標籤 |
| 細線 HAIR | #D5D1C8 | 分隔線、格線 |
| 朱紅 VERM | #B7322A | **唯一強調色**：重點數字、問號、印章、停扣區間 |
| 淺朱 VERM_T | #F0DCD6 | 圖表中的標示色帶 |
| 深藍 INDIGO | #16233B | 僅用於「最重要數字」的滿版頁，一組最多一張 |
| 暖灰 PAPER2 | #ECE9E2 | 清單、收藏用頁面 |

## 3. 字體（本機僅有思源，已定案）
- 標題：思源宋體 Light／Medium，字距 6–12。大數字用 Light 或 ExtraLight。
- 小字：思源黑體 Light／Regular，字距 2–5。
- 不用粗體、不用 Black 字重。

## 4. 固定元素
- 朱紅印章「帳」：封面與收尾各一，一頁最多一個。
- 方陣：30×12 = 360 個月；實心墨色方格 = 有投入，朱紅空心方格 = 停扣月份。
- 三欄數字列：標籤（灰）／數值（宋體 Light 70）／單位（宋體 Medium 30），終值用朱紅。
- 細線圖表：從 0 起算、格線 HAIR、一直投用墨、停扣用朱紅、停扣區間用 VERM_T 色帶、終點標註數值與差距。不得截斷座標軸放大差距。
- 每頁一個重點，版面各張不同（列表、方陣、圖表、數字、清單），但邊界與字體一致。

## 5. 內容誠信（品牌核心）
- 所有數字須由程式計算，不得手填、不得編造。
- 每個數據頁標明假設（每月投入、年化、複利方式）與「情境試算，非投資建議」。
- 每篇結尾提示結論的失效條件（報酬更低或中斷更久，結論會不同）。
- 不推薦個股、不給買賣點、不使用動漫角色名（宇智波等）。

## 6. 檔案
- `noirxu_style.py`：共用函式（frame、ttext、seal、matrix、stat_row、compound_series…）。
- `posts/`：每篇貼文一支腳本，import 上述模組出圖。
